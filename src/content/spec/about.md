我是一名热爱创造的技术探索者。在代码的世界里，我喜欢用逻辑去构建秩序；在文字的世界里，我试图用感性去捕捉生活。

::github{repo="LyraVoid/Mizuki"}

我日常关注的领域包括：
- **前端开发**：热衷于探索 Web 技术的边界，喜欢研究各种优雅的主题和交互。
- **开源文化**：喜欢阅读优秀的开源项目，偶尔也会贡献一些微小的代码。
- **生活随笔**：在 0 和 1 之外，我也喜欢记录生活中的小确幸、看过的电影和读过的书。
